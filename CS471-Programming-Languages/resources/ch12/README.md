Chapter 12 examples (inheritance, polymorphism, and basic OOP).

- Java: `Person.java`, `Student.java`, `Contact.java`, `Inheritance.java`, `Hide.java`, `Chess.java`, `Detergent.java`, `Jurassic.java`, `Cartoon.java`, plus supporting `Art.java` and `Drawing.java`. `TestPersonStudent.java` provides a quick main program.
- C++: `inheritance.cpp`, `polymorphism.cpp`, `pet.cpp`, `inclass_cpp_1.cpp`, `inclass_2_cpp.cpp`.
- Prebuilt binaries live in `bin/` for reference (`polymorphism`, `in_class_2`, and older `.class` files).

Compile examples
----------------
- Java: `javac *.java && java TestPersonStudent`
- C++: `g++ -std=c++17 polymorphism.cpp -o polymorphism_demo && ./polymorphism_demo`
