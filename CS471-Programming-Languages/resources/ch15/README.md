Chapter 15 Scheme examples (mirrored from `../../Assignments/Source-code`), normalized with `.scm` extensions.

Files
- `fact.scm`, `fact_main.scm`, `fact_display.scm`, `tail_factorial.scm` - factorial variants and entry points.
- `foo.scm`, `foo_main.scm`, `examples.scm`, `length.scm`, `quadratic.scm`, `compare.scm`, `hypot.scm` - assorted practice snippets.

Usage
- Any script with a shebang can run directly, e.g. `./fact_main.scm 5` (ensure `chmod +x` first) or `guile fact_main.scm 5`.
- The originals remain in `../../Assignments/Source-code` if you need the .txt counterparts.
