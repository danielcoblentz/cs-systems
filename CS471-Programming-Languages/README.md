# CS471 — Programming Languages

Organized course materials for CS471 (Programming Languages).

Top-level layout
----------------
- `assignments/` — homework, labs, and sample solutions (Scheme examples live in `assignments/Source code`).
- `lecture-slides/` — PDF slide decks organized by chapter/topic.
- `in-class-assignments/` — short in-class exercises, notes, and reference images.
- `final-project/` — presentation and write-up assets.
- `resources/` — reference PDFs, Lex/Yacc examples, OpenMP/MPI demos, and chapter-specific code.

Quick pointers
--------------
- Lex/Yacc demos: `resources/LexAndYaccCode/` (see `build.txt` for commands).
- Scheme samples: `assignments/Source code/README.md` explains how to run `.scm` files.
- Parallel programming snippets: see `resources/parallel/` for OpenMP (`openmp/`), MPI (`mpi/`), and Monte Carlo darts examples (`darts/`).
- Chapter 12 OO examples: `resources/ch12` now contains working Java and C++ snippets that compile out of the box.
