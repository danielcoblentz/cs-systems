# CS471 lecture slides

Slide decks for the semester, in roughly the order they were covered.

- `Chapter-3/chapter3.pdf` syntax and parsing
- `Chapter-4.pdf` lexical and syntax analysis
- `chapter5.pdf` names, bindings, and scope
- `chapter6.pdf` data types
- `chapter7.pdf` expressions and assignment
- `Programming-Language-Descriptions-and-Implementations.pdf` language
  description and implementation methods
- `Functional-Programming,-Part-I.pdf` and
  `Functional-Programming-Languages,-Part-2.pdf` functional programming
- `ch12.pdf` and `OO-Paradigm-Summary.pdf` object orientation
- `Chapter-11.pdf` abstract data types
- `Python-OO-programming.pdf` object orientation in Python
- `ch15_p1.pdf`, `ch15_p2.pdf`, `ch15_p3.pdf` Scheme and functional
  programming, in three parts
- `chapter16.pdf` logic programming
- `hpc-openmp.pdf` and `hpc-mpi.pdf` the parallel programming lectures behind
  the code in `../resources/parallel/`

`ch15_p1.pdf` and `Functional-Programming,-Part-I.pdf` are the same file under
two names.
